<h2>1. 上午市场主线</h2>
<p>上午盘面以算力硬件链条为主线：先进封装、PCB、存储、光通信等方向活跃，港股芯片股走强（中芯国际涨超5%）。政策与产业消息面上，广东算力&quot;十五五&quot;规划印发、英伟达要求停止向四个东南亚国家运送服务器、TrendForce 存储供需分化判断、国家统计局1—10月分行业利润数据等构成主要事实输入。美股夜盘 SpaceX 因获批发射100万颗卫星部署太空数据中心涨超2%，带动存储、光通信、AI数据中心相关概念股普涨。以上为研究性梳理，非收益承诺。</p>
<h2>2. 盘中新事件</h2>
<h3>事件一：英伟达要求制造合作伙伴停止向四个东南亚国家运送服务器</h3>
<ul>
<li><strong>事件</strong>：财联社11月27日早间新闻精选（发布于2026-11-27 08:03）提及，英伟达已要求其制造合作伙伴停止向马来西亚、新加坡、泰国和印度尼西亚四个东南亚国家运送服务器；戴尔、超微电脑等厂商已通知相关买家，英伟达不允许相关订单发货。</li>
<li><strong>新增信息</strong>：本窗口新增的事实为上述发货限制安排及其覆盖的四个国家名单。</li>
<li><strong>直接影响</strong>：若该限制持续执行，上述四国市场的服务器到货节奏可能受到影响；涉及厂商对当地买家的在手订单交付存在不确定性。</li>
<li><strong>一阶产业链影响</strong>：若订单停滞范围扩大，则服务器整机厂商在上述区域的出货可能被推迟，相关渠道库存与交付计划需重新评估。</li>
<li><strong>二阶产业链影响</strong>：若整机出货受限传导至上游，则服务器零部件、配套供应链在对应区域的订单节奏可能同步后移。</li>
<li><strong>核心公司映射</strong>：英伟达、戴尔、超微电脑（新闻原文提及）。</li>
<li><strong>反向风险</strong>：若后续出现豁免、订单结构调整或限制范围收窄，则上述影响可能明显减弱。</li>
</ul>
<h3>事件二：美国监管批准 SpaceX 发射100万颗卫星部署太空数据中心</h3>
<ul>
<li><strong>事件</strong>：富途牛牛2026-11-27 09:16报道，美股夜盘 SpaceX 涨超2%，美国监管批准&quot;SpaceX发射100万颗卫星部署太空数据中心&quot;。</li>
<li><strong>新增信息</strong>：监管批准事项与 SpaceX 盘前/夜盘行情表现。</li>
<li><strong>一阶产业链影响</strong>：若太空数据中心建设逐步落地，则卫星制造与发射服务、星载/地面通信设备需求可能相应增加。</li>
<li><strong>二阶产业链影响</strong>：若星座与算力部署规模扩大，则地面配套网络、散热与电源等环节的远期需求可能被重估。</li>
<li><strong>核心公司映射</strong>：SpaceX（非上市主体，映射以美股相关概念板块行情为准）。</li>
<li><strong>反向风险</strong>：若后续出现监管复核、部署计划推迟或资本开支不及预期，则相关情绪交易可能回吐。</li>
</ul>
<h3>事件三：广东印发算力发展&quot;十五五&quot;规划</h3>
<ul>
<li><strong>事件</strong>：财联社2026-11-27 08:03早间新闻精选提及，广东省政务服务和数据管理局、省发展改革委印发《广东省算力发展&quot;十五五&quot;规划》，提出到2028年智算规模突破1000EFlops（FP16），全省数据中心绿电使用占比超80%，鼓励算力中心优先使用国产算力芯片，并推进国产大模型、CANN生态、昇腾算子库等生态体系构建。</li>
<li><strong>新增信息</strong>：规划正式印发及其量化目标与生态建设方向。</li>
<li><strong>直接影响</strong>：若规划目标按节奏推进，则广东区域内智算中心投资、国产算力芯片采购与绿电配套建设需求可能提升。</li>
<li><strong>一阶产业链影响</strong>：若智算建设放量，则服务器整机、电源、散热、数据中心建设运营环节订单可能增加；国产芯片与配套软件生态（昇腾方向）在区域内渗透率可能提升。</li>
<li><strong>二阶产业链影响</strong>：若国产芯片采购规模扩大，则上游先进封装、存储配套、国产化替代链条的区域内需求可能被带动。</li>
<li><strong>核心公司映射</strong>：新闻原文提及 CANN 生态、昇腾算子库方向（华为生态体系），未点名具体上市公司；具体受益标的需另行核实。</li>
<li><strong>反向风险</strong>：若地方落地细则、资金安排或建设进度不及规划目标，则相关预期可能下修。</li>
</ul>
<h3>事件四：TrendForce 判断存储市场 DRAM 与 NAND 前景分化</h3>
<ul>
<li><strong>事件</strong>：富途牛牛2026-11-27 10:08报道，TrendForce 最新报告指出，存储芯片 DRAM 与 NAND 市场前景明显分化：DRAM 预计持续供不应求，NAND 闪存价格预计最早将于明年第一季度开始下跌。</li>
<li><strong>新增信息</strong>：第三方机构的供需与价格路径预测。</li>
<li><strong>直接影响</strong>：若预测兑现，则 DRAM 相关厂商盈利弹性维持，NAND 链条价格压力可能在明年一季度后显现；当日港股芯片股走强（中芯国际涨超5%，壁仞科技、华虹宏力、天数智芯、英诺赛科等跟涨）。</li>
<li><strong>一阶产业链影响</strong>：若 DRAM 持续紧缺，则模组、服务器内存配套环节成本压力上升；若 NAND 转向跌价，则下游存储买家可能推迟采购、渠道库存意愿下降。</li>
<li><strong>二阶产业链影响</strong>：若价格路径兑现，则整机与终端厂商的 BOM 结构和备货策略可能调整，进而影响上游封测与材料环节的排产。</li>
<li><strong>核心公司映射</strong>：新闻原文提及美光科技、闪迪、希捷科技、西部数据、慧荣科技（前夜行情）；港股芯片股提及中芯国际、壁仞科技、华虹宏力、天数智芯、英诺赛科。</li>
<li><strong>反向风险</strong>：若需求超预期或供给收缩，则 NAND 跌价时点可能推迟，DRAM 紧缺程度亦可能变化。</li>
</ul>
<h3>事件五：国家统计局公布1—10月分行业利润</h3>
<ul>
<li><strong>事件</strong>：财联社2026-11-27 09:33报道，国家统计局数据显示，1—10月份计算机、通信和其他电子设备制造业利润同比增长1.0倍；汽车制造业下降26.0%；非金属矿物制品业下降46.7%。</li>
<li><strong>新增信息</strong>：官方分行业利润增速数据。</li>
<li><strong>直接影响</strong>：若该趋势延续，则电子设备制造板块盈利预期相对占优，汽车与非金属矿物制品链条盈利压力仍在释放。</li>
<li><strong>一阶产业链影响</strong>：若电子行业利润高增延续，则其上游元器件、材料环节的议价与扩产节奏可能同步改善。</li>
<li><strong>二阶产业链影响</strong>：若汽车链条利润持续收缩，则整车及零部件厂商的资本开支与价格策略可能趋于保守，传导至上游零部件采购。</li>
<li><strong>核心公司映射</strong>：数据为行业层面，未点名公司。</li>
<li><strong>反向风险</strong>：若后续月份利润结构变化（如汽车价格战缓和、电子基数抬升），则上述分化判断可能收敛。</li>
</ul>
<h3>事件六：全球电子协会预计 PCB 供应瓶颈至少持续到2027年上半年</h3>
<ul>
<li><strong>事件</strong>：财联社2026-11-27 08:31报道，全球电子协会预计供应瓶颈至少持续到2027年上半年，2028年中期之前可能都难有实质性缓解，PCB 短缺带来的风险可能与2021年芯片短缺相当。前一交易日 PCB 概念领涨算力硬件股：中京电子盘中一度6连板，骏亚科技、澳弘电子、崇达技术封涨停，金百泽、金禄电子、奥士康一度封板（此为上一交易日行情，非本窗口新增事实）。</li>
<li><strong>新增信息</strong>：机构对 PCB 供应瓶颈持续时间与严重程度的预期。</li>
<li><strong>直接影响</strong>：若瓶颈兑现，则 PCB 产能紧张与涨价预期延续，相关公司订单与产能利用率有望维持高位。</li>
<li><strong>一阶产业链影响</strong>：若 PCB 供给受限，则服务器、交换机等算力硬件厂商的成本与交付周期可能上行，高端 PCB（高多层、HDI）紧缺更突出。</li>
<li><strong>二阶产业链影响</strong>：若整机交付受阻，则算力集群建设节奏与上游覆铜板、铜箔、玻纤布等原材料需求结构可能重排。</li>
<li><strong>核心公司映射</strong>：中京电子、骏亚科技、澳弘电子、崇达技术、金百泽、金禄电子、奥士康（行情报道提及）。</li>
<li><strong>反向风险</strong>：若行业扩产快速落地或需求走弱，则瓶颈缓解时点可能提前，涨价与订单预期回落。</li>
</ul>
<h3>事件七：华为4篇论文进入 ISSCC 2027 议程草案，含自研 HBM 内存方案</h3>
<ul>
<li><strong>事件</strong>：据《科创板日报》报道（财联社2026-11-27 08:31、10:46转述），IEEE 公布 ISSCC 2027 会议议程草案，华为共有4篇论文进入技术议程，包括 HBM 内存方案、采用逻辑折叠技术的旗舰移动 SoC 等。当日先进封装概念反复走强：华海诚科、康强电子涨停，三佳科技2连板，鸿富诚、精测电子、芯碁微装、中科飞测、微导纳米均涨超10%。</li>
<li><strong>新增信息</strong>：议程草案中华为论文构成的技术信号。</li>
<li><strong>一阶产业链影响</strong>：若自研 HBM 方案后续推进落地，则先进封装、测试设备、封装材料需求可能提升。</li>
<li><strong>二阶产业链影响</strong>：若国产 HBM 形成供给能力，则国产算力芯片的存储配套自主化程度提高，相关国产存储与封测链条的市场空间可能扩大。</li>
<li><strong>核心公司映射</strong>：华海诚科、康强电子、三佳科技、鸿富诚、精测电子、芯碁微装、中科飞测、微导纳米（行情报道提及）；论文属技术议程草案，产品化进度未知。</li>
<li><strong>反向风险</strong>：若议程草案后续调整或技术方案进度不及预期，则相关主题热度可能消退。</li>
</ul>
